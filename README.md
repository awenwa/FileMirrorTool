# FileMirrorTool

Windows 文件镜像同步工具 —— 将网络文件夹通过符号链接镜像到本地。

## 功能

- **Link 模式**：创建符号链接（需管理员权限）
- **Mirror 模式**：直接复制文件
- **Mix 模式**：按条件筛选，符合条件的复制，其余创建符号链接

## 特性

- 方案管理：保存、载入、一键再次同步
- 条件筛选：按文件大小、扩展名、逻辑组合
- 实时进度：统计和同步过程均有进度反馈
- 拖动调整：左右面板宽度可自由拖动

## 使用

直接运行 `FileMirrorTool.exe`，无需安装 Python。

Link 模式需要管理员权限，首次运行会弹出 UAC 确认框。
